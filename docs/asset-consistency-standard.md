# 素材一致性规范

每个游戏至少维护一个版本化 StyleProfile，包括视角、透视、美术风格、轮廓、色板、光源、阴影、背景与透明要求、角色/塔比例、帧画布、tile size、默认 FPS、朝向数、Prompt 前缀、负面 Prompt 和参考图。

生成前自动注入当前 StyleProfile，并展示最终 Design Spec、Prompt 和负面 Prompt 供用户确认。参考图以文件记录 ID 关联，禁止只存临时 URL。生成结果保存模型、完整提示词、模型参数、seed、时间、父版本和 StyleProfile 版本。

重新生成或扩展动画必须引用上一版本主图、参考图和 StyleProfile，校验脸部、服装、武器、配色、体型、视角、帧尺寸、阴影和技能颜色一致。动画新增动作创建新 AssetVersion 并沿用帧画布、FPS 与朝向定义。

已发布资源和文件不可直接覆盖；任何修改创建新版本，审核通过后再切换当前版本，旧版本保持可追溯与可导出。
